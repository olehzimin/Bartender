# Bartender – Your Personal Cocktail Assistant

**Bartender** is an iOS mobile app companion that puts a full cocktail library in your pocket. Whether you're hosting a party, experimenting with home bartending, or just trying to find the perfect drink for the night, Bartender helps you discover, create, and organize cocktails effortlessly.

The app offers a rich catalog of popular and classic cocktails, and a search tool to help you find drinks by name or by available ingredients based on a custom [Cocktail API](https://github.com/olehzimin/cocktail-api).


## ✨ Core Features

- **Browse Popular Cocktails**  
  Instantly view a curated list of trending and classic cocktail recipes.

- **Search Functionality**  
  Search for cocktails by **name** or find drinks by **ingredient**.

- **Bartender Search**  
  Get personalized drink recommendations based on your flavor, alcohol level and ingredient preferences.

- **Custom Recipes**  
  Create and save your own cocktail creations. Upload a photo, list ingredients, and write instructions.


## 🛠️ Tech Stack

- **UI Framework**: SwiftUI
- **Language**: Swift
- **Networking**: URLSession
- **Data Persistence**: SwiftData / UserDefaults
- **API Integration**: RESTful custom [Cocktail API](https://github.com/olehzimin/cocktail-api)
